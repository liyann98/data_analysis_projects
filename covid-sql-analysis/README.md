# COVID-19 Deaths Analysis — United States

## Overview
Exploratory SQL analysis of global pandemic spread using 
COVID-19 deaths data. Demonstrates advanced SQL techniques 
for data analysis.

## SQL Techniques Used
- Window functions
- CTEs (Common Table Expressions)
- Temporary tables
- Aggregations and joins
- Rolling calculations

## Tools & Technologies
- SQL Server
- Excel
- Tableau

## Key Analysis
- Death rates by country and continent
- Rolling death totals over time
- Population vs death percentage comparisons
