# Restaurant Recommendation System

## Overview
Data-driven recommendation engine built by merging and 
analysing four real-world datasets to segment customers 
and personalise restaurant recommendations.

## Datasets Used
- Vendor, Order, Customer, Location (Kaggle)

## Key Steps
1. Merged and cleaned four datasets
2. End-to-end EDA — univariate, bivariate, multivariate
3. K-Means clustering to segment customers by spend 
   and order frequency
4. Identified loyalty targets and premium segments

## Tools & Technologies
- Python, Pandas
- K-Means Clustering
- Matplotlib, Seaborn
