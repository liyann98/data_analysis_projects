# Spotify Genre Classification & Recommendation System

## Overview
Investigated limitations of Spotify's collaborative filtering 
algorithm and proposed a genre classification solution using 
audio feature clustering.

## Approach
- Accessed 9 audio features via Spotify API
- Applied K-Means clustering with silhouette and elbow analysis
- Produced more musically meaningful genre groupings

## Key Topics
- Recommendation system improvement
- Algorithmic bias and ethical implications
- Audio feature analysis

## Tools & Technologies
- Python, Spotify API
- K-Means Clustering
- Silhouette analysis, Elbow method
