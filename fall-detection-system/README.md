# ML-Based Real-Time Fall Detection System

## Overview
Machine learning model to detect falls using accelerometer 
and gyroscope sensor data. Designed for real-world deployment 
in elderly care settings.

## Results
- Random Forest classifier: 95% accuracy
- Designed for real-time inference on sensor data

## Tools & Technologies
- Python, Scikit-learn
- Pandas, NumPy
- Accelerometer and gyroscope sensor data

## Key Steps
1. Sensor data preprocessing and feature extraction
2. Random Forest classification
3. Model evaluation and optimisation
4. Real-world deployment design for elderly care
