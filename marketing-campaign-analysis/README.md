# Marketing Campaign Response Analysis

## Overview
End-to-end analytics pipeline on customer campaign response 
data with an interactive R Shiny dashboard for business 
stakeholders.

## Key Features
- Data cleaning with Python and Pandas
- Interactive R Shiny dashboard
- KPIs tracked: ROI, CTR, conversion metrics
- Segment-level performance analysis

## Tools & Technologies
- Python, Pandas
- R, R Shiny
- ggplot2
